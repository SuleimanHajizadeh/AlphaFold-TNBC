# TAP38 / PPH1 (Thylakoid-Associated Phosphatase 38)

**TAP38** (also termed **PPH1** - *Photosystem II Core Phosphatase / Protein Phosphatase 1*, At4g27800) is a monomeric protein phosphatase located in the chloroplast thylakoid membrane of photosynthetic plants. It acts as the direct enzymatic antagonist to the kinase [[STN7]].

---

## ⚡ Role in Dephosphorylating LHCII & Driving State 1 Transitions

```
STN7 Kinase (Active under PSII light / reduced PQ)
             │
             ▼ Phosphorylates LHCII (Thr-3)
      [ P-LHCII in State 2 (PSI bound) ]
             │
             ▼ Dephosphorylates LHCII (Far-red / Dark / oxidized PQ)
TAP38 / PPH1 Phosphatase
             │
             ▼
      [ Unphosphorylated LHCII in State 1 (PSII bound) ]
```

1. **Specific Substrate Dephosphorylation**: TAP38 selectively dephosphorylates the N-terminal phosphothreonine residues of **[[LHCII]]** trimers (Lhcb1/Lhcb2).
2. **Reversibility of [[Thylakoid State Transitions]]**: Unlike [[STN7]] which is regulated by the redox state of the plastoquinone pool via [[Cytochrome b6f]], TAP38 exhibits constitutive basal activity. When STN7 is inactivated (under far-red light or darkness), TAP38 rapidly dephosphorylates LHCII, causing it to dissociate from PSI and return to PSII.
3. **Contrast with PBCP**: While TAP38 dephosphorylates antenna complexes (LHCII), a distinct phosphatase (**PBCP** - *Photosystem II Core Phosphatase*) dephosphorylates the PSII core reaction center proteins targeted by [[STN8]].
