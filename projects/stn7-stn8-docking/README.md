# STN7/STN8 Chloroplast Thylakoid Kinases Computational Research Pipeline

This repository hosts a publication-quality, fully reproducible computational structural bioinformatics research pipeline for the comparative and evolutionary analysis of chloroplast thylakoid kinases **STN7** and **STN8** in higher plants and green algae.

This workflow is optimized to support the generation of quantitative and visual datasets suitable for a Scopus/Web of Science peer-reviewed manuscript.

---

## 🔬 Scientific Overview

This pipeline addresses key molecular questions regarding the regulatory chloroplast kinases **STN7** (essential for Photosystem II to Photosystem I state transitions) and **STN8** (essential for Photosystem II core protein repair under high-light stress). 

Key features include:
1. **Dynamic AlphaFold Structure Retrieval:** Automatically queries the AlphaFold Protein Structure Database API to obtain and download the latest high-resolution models (fetching active **v6** PDB structures).
2. **Homology Mapping & Star-Alignment:** Downloads high-confidence orthologs spanning dicots (*Arabidopsis thaliana*), monocots (*Oryza sativa*, *Zea mays*), and green algae outgroup (*Chlamydomonas reinhardtii*), performing Multiple Sequence Alignment (MSA) using a pure Python Star-Alignment algorithm leveraging Biopython's pairwise engine.
3. **Local Structural Superposition:** Pairs structural residues according to domain alignments and superimposes C-alpha coordinates of STN8 onto STN7 in 3D space using singular value decomposition (SVD) to calculate local Root-Mean-Square Deviation (RMSD).
4. **Residue-Level B-Factor (pLDDT) Profiling:** Characterizes AlphaFold structural confidence across stromal kinase domains vs transit peptides and terminal regions.
5. **Kyte-Doolittle Hydrophobicity Analysis:** Profiles membrane-association regions using a sliding window approach (w=19).
6. **Robust Statistical Validation:** Calculates Shannon Entropy for residue conservation, Student's t-test comparing domain confidence, and Pearson Correlation of hydrophobicity.

## 📊 Summary of Pipeline Findings

A brief overview of the quantitative results generated by running this pipeline:
* **Paralog Conservation:** Arabidopsis STN7 and STN8 exhibit **36.12%** sequence identity, reflecting ancient duplication.
* **Evolutionary Conservation:** Across monocots, dicots, and algae, **57.02%** of alignment columns (621 out of 1089 columns) are perfectly conserved (Shannon Entropy $H = 0.0$).
* **Structural Kinase Domain Similarity:** Structural superposition maps **173 C-alpha atoms** in the stromal catalytic core, with an RMSD of **4.2507 Å**. Active sites are tightly matched.
* **Model Confidence Validation:** Kinase domains have very high definition (Mean pLDDT ~85) compared to flexible loops, supported by Student's t-test ($p < 0.001$).
* **Membrane Association Dynamics:** Neither kinase has a classic transmembrane helix $> 1.6$. Highest peaks are **1.49** (STN7) and **1.59** (STN8), showing atypical thylakoid association. Hydrophobicity profiles are significantly correlated (Pearson $r = 0.2039$, $p < 0.05$).
