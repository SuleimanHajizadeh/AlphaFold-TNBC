# Raw Sources Directory

This directory holds the immutable, primary source documents for the LLM Wiki.

## Structure
- `papers/` — PDF, markdown, or plain text academic papers and preprints.
- `articles/` — Web clippings, technical blogs, and saved documentation.
- `transcripts/` — Lecture notes, discussion logs, and meeting transcripts.
- `assets/` — Local figures, diagrams, and images downloaded from sources.

> [!NOTE]
> Files in this directory are read-only for the LLM agent. The agent extracts knowledge from here into `wiki/`, but never modifies raw sources directly.
